Computers are good at repetition, and loops are how you ask for it. A for loop runs the same code once for every item in a list, or every number in a range. In this module you'll loop over a list, count with range, and learn the running-total pattern: start at zero, then add a little each time round. You'll also meet the while loop, which repeats as long as a condition stays true, and the words break and continue, for stopping early or skipping an item. This is where programs start to feel powerful. Let's loop.
