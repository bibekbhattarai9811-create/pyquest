This module is a handful of useful extras. You'll meet the tuple, which is like a list but fixed, and the set, which quietly removes duplicates. You'll loop with enumerate to get a position and an item together, and build a whole list in a single line with a comprehension. You'll catch an error with try and except so your program doesn't crash, and use import to borrow ready-made code, like the math module for square roots. None of these are essential on day one, but you'll see them in real code all the time. Let's take a look.
