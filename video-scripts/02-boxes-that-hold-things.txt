A program isn't much use if it forgets everything the moment it runs. Variables are how Python remembers. A variable is just a name that holds a value: you write the name, an equals sign, then the value. In this module you'll make your first variables, use them more than once, change what they hold, and use them in a calculation. You'll also learn the simple rules for naming them: letters, numbers, and underscores, but no spaces. Every lesson is one small change, like switching a zero to a five. Once variables click, a lot of programming is just moving values from one box to another. Let's make our first box.
