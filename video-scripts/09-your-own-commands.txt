So far you've been using Python's built-in commands, like print. Functions let you make your own. You define one with the word def, give it a name, and then call it whenever you need it. In this module you'll write a function, pass a value into it through a parameter, and, the important part, return a value back out so the rest of your program can use the result. You'll see clearly why return is not the same as print. Functions are how real programs stay organised instead of turning into one long mess. Let's define one.
