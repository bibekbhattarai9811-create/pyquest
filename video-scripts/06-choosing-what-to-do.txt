Now your programs can make decisions. An if statement runs a block of code only when a condition is true. In this module you'll write your first if, add an else for the other case, and use elif to check several possibilities in order, where the first match wins. You'll also watch out for the two things beginners trip on: the colon at the end of the if line, and the indent on the line below it. Every lesson is one small change to a working example. Let's make Python choose.
