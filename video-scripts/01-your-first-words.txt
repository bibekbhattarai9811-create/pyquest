Welcome to Python. Before a program can do anything clever, it has to do something you can see, and the simplest way is to print a message to the screen. In this first module you'll learn the print command: how to show text, how to show numbers, how to print several things on one line, and how to leave a comment, which is a note for yourself that Python ignores. These are tiny steps, and that's on purpose. Each lesson changes just one line of code. By the end you'll have run your first few Python programs and you'll feel at home in the editor. Let's start by making Python say hello.
