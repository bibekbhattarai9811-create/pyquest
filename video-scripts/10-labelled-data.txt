A list finds things by position: item zero, item one, item two. A dictionary finds them by a name you choose. You write a key, a colon, and a value, inside curly braces, like name colon Ada. In this module you'll build a dictionary, look up a value by its key, add and change keys, and handle the case where a key isn't there, using dot get with a fallback. Dictionaries are how data arrives from the internet, so this one pays off quickly. Let's build one.
