Text is everywhere in programs: names, messages, labels, prompts. Python calls a piece of text a string, and this module is all about handling it. You'll join two strings together, deal with the classic missing-space problem, and then meet f-strings, which are the clean way to drop a variable straight into a sentence. You'll also count the letters in a string and change its capitalisation. These are small skills, but you'll use f-strings in almost every program you ever write, so it's worth getting comfortable. Let's start with quotes.
