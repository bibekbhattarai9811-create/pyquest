## Making the computer talk

Every program's job is to *do something you can observe*. The simplest observable
thing in Python is printing text to the screen with the built-in `print` function.

```python
print("Hello!")
```

- `print` is the name of the function.
- The parentheses `( )` mean "call this function now".
- The text inside the quotes `"..."` is called a **string** — a piece of text.

You can print numbers too, and you don't use quotes for those:

```python
print(2026)
```

Whatever you put inside the parentheses gets shown, followed by a new line.

### Watch out for

- The quotes must match: `"Hello"` is fine, `"Hello'` is an error.
- Python cares about capital letters. `Print` is not the same as `print`.
- Punctuation inside the string is printed exactly as you type it.
